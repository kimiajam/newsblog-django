# NewsBlog

A modern Django news website built with the Tailnews template.

## Features

- News categories
- Search functionality
- Article details and comments
- Author profiles
- Contact form
- Responsive design

## Tech Stack

- Python
- Django
- SQLite
- HTML / Tailwind CSS
- JavaScript

## Run Locally

```bash
git clone <repository-url>
cd Newsblog
python manage.py runserver
